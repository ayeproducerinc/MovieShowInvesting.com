On both desktop and mobile, the public project page shows the trailer as the main media when available; otherwise it shows the poster. Never show both together. The owner chose the pledge-and-confirmed-interest panel directly below the main media.

**Why:** The owner explicitly clarified and confirmed the final desktop and mobile choices after earlier sketches showed both media together.

**How to apply:** Keep the trailer-or-poster rule when revising public project layouts. Preserve a prominent pledge action, honest non-binding interest labels, visible no-payment/risk disclosures, and existing eligibility and account-specific action states.
