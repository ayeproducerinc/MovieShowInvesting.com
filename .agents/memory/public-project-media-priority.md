name: Public project media priority
description: Owner-approved trailer-or-poster and pledge hierarchy for both desktop and mobile public project pages
---

On both desktop and mobile, the public project page shows the trailer as the main media when available; otherwise it shows the poster. Never show both together. The owner chose the pledge-and-confirmed-interest panel directly below the main media.

On Explore, show a project's poster when it has one, even when it also has a video. This rule applies to all existing and future projects.

**Why:** The owner explicitly clarified and confirmed the final desktop and mobile choices after earlier sketches showed both media together, and separately requested posters on Explore with video priority on actual project pages.

**How to apply:** Keep posters on Explore and the trailer-or-poster rule on actual project pages when revising shared layouts. Preserve a prominent pledge action, honest non-binding interest labels, visible no-payment/risk disclosures, and existing eligibility and account-specific action states.
